# **App Name**: SalesPro Hub

## Core Features:

- Customer Database: Create and manage a customer database with detailed profiles, interactions, and needs. Features: add customer profile, edit, and view all customer details. Utilizes Firestore.
- Concern Analyzer: Analyze customer objections to identify and display the most common concerns. Feature to add a concern to a profile. Aggregate the number of same concerns. Utilize AI to summarize, shorten, and provide better category suggestions for concerns. Summaries must act as a tool.
- Knowledge Base: Develop a searchable knowledge base with pre-prepared information and answers to frequently asked questions. Feature to search an item.
- Skill Reminder: Display a persistent reminder of key sales skills in a bottom bar.

## Style Guidelines:

- Primary color: Navy blue (#34495E) for a professional and trustworthy feel.
- Background color: Light gray (#F4F6F6) for a clean and modern look.
- Accent color: Teal (#008080) to highlight key information and calls to action.
- Body and headline font: 'Inter' sans-serif font for a clean, modern, and highly readable interface.
- Use simple and professional icons to represent different features and actions.
- Maintain a clean and organized layout with clear visual hierarchy.
- Subtle transitions and animations to enhance user experience without being distracting.
